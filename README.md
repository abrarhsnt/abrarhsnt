## Professional Experience

### Research Assistant @ BIOSE Lab, BRAC University *(2023 – Present)*

- **Data Curation & Processing**: Built an end-to-end data pipeline using Pandas and NumPy to clean, normalize, and combine medical datasets from RSNA Pneumonia and Heart Disease Health Indicator datasets, processing **50,000+ patient records** while handling missing values and outliers.

- **Predictive Modeling**: Developed a custom ResNet-50 model for pneumonia classification achieving **92% accuracy** and built a weighted ensemble model combining deep learning and tree-based methods for heart disease prediction, with hyperparameter tuning using Scikit-learn's GridSearchCV.

- **Statistical Analysis & Interpretability**: Applied SHAP and surrogate decision trees to explain model predictions and identify key clinical features, while using LIME-constrained Grad-CAM visualizations to improve model interpretability.

- **Research & Publication**: Contributed to writing two first-author research manuscripts by conducting literature reviews, designing experiments, analyzing results, and preparing manuscripts in LaTeX.

## Selected Projects

### [Interpretable Heart Disease Prediction via a Weighted Ensemble Model](https://github.com/abrarhsnt/cvd-xai)
> Weighted ensemble model (LightGBM + XGBoost + CNN) for cardiovascular disease prediction using **229,781 patient records**, with SHAP explanations and surrogate decision trees for clinical interpretability.

- **Tech Stack**: Python, LightGBM, XGBoost, CNN/Deep Learning, SHAP, Scikit-learn, Pandas, NumPy, Matplotlib
- **Key Result**: Achieved test AUC of **0.8371** with 80.0% recall, incorporating SHAP global/local explanations and a surrogate decision tree (89.9% agreement) for interpretable clinical risk prediction.

---

### [Interpretable Pneumonia Detection from Chest X-Rays](https://github.com/abrarhsnt/pneumonia-xai)
> ResSENet-50 with Few-Shot Learning for pneumonia detection, using LIME and Grad-CAM++ with fusion for transparent visual explanations.

- **Tech Stack**: Python, TensorFlow/Keras, ResNet-50, Squeeze-and-Excitation, Few-Shot Learning, LIME, Grad-CAM++
- **Key Result**: **84.0% validation accuracy** and 0.87 AUC-ROC with fused LIME and Grad-CAM++ explanations highlighting clinically relevant lung regions.

---

### [CricAnalytics: Interactive Cricket Dashboard](https://github.com/abrarhsnt/CricAnalytics)
> Interactive dashboard for analyzing IPL ball-by-ball data with dynamic player and team insights.

- **Tech Stack**: Python, Pandas, Plotly, Streamlit, GitHub
- **Key Result**: Live web application with interactive cricket analytics and visualizations.
